# automated-invoice-generator
A Python-based automation tool that generates invoices from Excel data, reducing repetitive manual data entry for import-export documentation.

## Dataset Note
The sample dataset uses Indonesian column names to reflect real-world import-export invoice workflows. This demonstrates the ability to work with localized operational data while keeping the project safe for public sharing.

## Features
- Reads shipment and invoice data from Excel.
- Automatically generates PDF invoices.
- Reduces repetitive manual data entry.
- Uses fictional data for safe public demonstration.

## Tools
- Phyton
- Pandas
- Microsoft Excel

## Output
Generates sample invoices in PDF format.
